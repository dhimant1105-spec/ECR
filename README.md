# PF ECR Calculator

A standalone browser-based PF contribution calculator prototype.

## Publish on GitHub Pages

1. Create a **public** GitHub repository (for example, `pf-ecr-calculator`).
2. Upload `index.html` and `README.md` from this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for deployment. Your URL will usually be:
   `https://YOUR-USERNAME.github.io/pf-ecr-calculator/`

## Important notes

- This prototype performs calculations in the browser; it does not upload employee data to a server.
- Do not commit real employee payroll data to a public repository.
- The export is a calculation CSV and has not been verified as an official EPFO ECR upload file.
- Confirm the pension-member formula and applicable statutory rules before using calculations for official filings.
